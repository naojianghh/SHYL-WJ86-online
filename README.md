# SHYL-WJ86 微机原理接口实验箱 · 在线模拟

一个离线可用的单页 Web 模拟器，用浏览器模拟 SHYL-WJ86 新型微机原理接口实验系统实验箱的
主要实验电路：8086 实模式 CPU、8253/8254 定时计数器、8255 并行接口、8259 中断控制器、
DAC0832、ADC0809，以及 8 位数码管、8 个 LED、8×8 点阵、逻辑开关和单脉冲按钮。

内置 MASM 子集汇编器，可以直接载入并运行实验指导书里的 `.ASM` 文件，在面板上看到
LED、数码管、点阵、万用表和示波器的实时反应。

## 快速开始

1. 双击 `index.html`，用 Chrome / Edge 打开（无需服务器、无需联网）。
2. 页面默认载入“考试综合模板”并开始运行。
3. 在“程序”页粘贴或打开自己的 `.ASM`，点右上角 **汇编并运行**（或 `Ctrl+Enter`）。
4. 在“接线”页按实验指导书调整接线；在“芯片”页查看 8253/8255/8259 的寄存器状态。

支持 UTF-8 与 GBK/GB18030 编码的汇编源文件，打开时自动识别。

## 窗口布局

- 拖动实验箱面板与程序栏之间的**竖直分隔条**，可调节程序栏宽度；双击分隔条复位。
- 拖动编辑器与输出日志之间的**横向分隔条**，可调节日志高度；双击复位。
- 标签栏右侧的 **⤢ 放大** 让当前标签页占满窗口（程序、寄存器、芯片、接线、说明都可用），按 `Esc` 或 **⤡ 还原** 退出。
- **折行** 开关让长汇编行自动换行，适合窄窗口。
- 程序栏宽度、日志高度和折行状态会保存在本机浏览器中，下次打开自动恢复。

## 打开与保存

- 用 **打开 .ASM** 通过系统文件选择器打开文件后，程序栏会保留该文件的写入句柄；
  点 **保存**（`Ctrl+S`）直接写回原文件。
- **另存为**（`Ctrl+Shift+S`）选择新位置和文件名。
- 如果通过普通文件框或内置示例载入，没有原文件写入句柄，保存会转为“另存为”；
  浏览器不支持 File System Access API 时退化为下载副本。
- 自动识别 UTF-8 / GBK，并按原编码、原换行符写回。GBK 无法表示的字符会写成 `?`。
- 编辑器上方显示当前文件名和“示例 / 已保存 / 未保存的修改”等状态；有未保存修改时
  关闭页面会提示。

## 端口与默认接线

| 器件 | 端口 | 默认接线 |
| --- | --- | --- |
| 8253/8254 | 200H~203H | 1 MHz→CLK0，GATE0~2→+5V，OUT0→8259 IRQ0 |
| 8255 | 210H~213H | PA=数码管段码/点阵行，PB=LED/点阵列，PC=位选 |
| 8259 | 230H（偶）/231H（奇） | IRQ1←0809 EOC，IRQ2←AN2 单脉冲 |
| DAC0832 | 250H | U = 10·N/256 − 5（V，双极性） |
| ADC0809 | 260H~267H | IN0←面板电位器 0~5 V，转换时间 100 µs |

“接线”页是一张**自由接线表**：每个目的端用下拉框选择任意信号源，同一信号可以同时接多路。目的端包括：

- `CLK0`~`CLK2`：固定脉冲（1 MHz、500 kHz、100 kHz、10 kHz、1 kHz、100 Hz、10 Hz、1 Hz）、
  `OUT0`~`OUT2`、`AN1`、`K1`~`K12`、`GND`；
- `GATE0`~`GATE2`：`+5V`、`GND`、`OUT0`~`OUT2`、`AN1`、`AN2`、`K1`~`K12`；
- `IRQ0`~`IRQ7`：`OUT0`~`OUT2`、`EOC`、`AN1`、`AN2`、`K1`~`K12`、`+5V`、`GND`、`NC`；
- `PC0`~`PC7`：`OUT0`~`OUT2`、`EOC`、`AN1`、`AN2`、`K1`~`K12`、`+5V`、`GND`；
- `L1`~`L8`：`PB0`~`PB7`、`PA0`~`PA7`、`OUT0`~`OUT2`、`AN1`、`AN2`、`K1`~`K12`、`+5V`、`GND`、`NC`。

8255 的 `PA0`~`PA7`、`PB0`~`PB7`、`PC0`~`PC7` 引脚也可以作为任意一路的源。
常用组合有“默认接线”“8253 级联”“1 ms 节拍→PC7”“点阵接线”“交通灯”五个预设按钮。
显示部分另有数码管位选端口（PC/PB）、点阵接法、点阵方向（0/90/180/270°，默认顺时针 90°）、
共阳/共阴、位选极性和 LED 极性。

## 数码管位序

- 考试模板按 **PC0 最右** 编写，默认位序即为 PC0 最右。
- 部分实验代码按 **PC0 最左** 编写（如实验四的 ADC 显示、实验五的按键显示）。
  内置示例已按各自代码设置；手动载入这些文件时，到“接线”页勾选
  **数码管位序反转（PC0 最左）** 即可。
- 实验四-3 用 **PB** 做位选，需把“数码管位选端口”改为 PB。

## 汇编器与 CPU 支持范围

- 伪指令：`.8086`、`.386`、`.486`、`.MODEL SMALL`、`.STACK`、`.DATA`、`.CODE`、
  `NAME SEGMENT/ENDS`、`ASSUME`、`PROC/ENDP`、`EQU`、`DB/DW/DD`、`DUP`、`END`。
- 指令：8086 常用整数指令，含 `MOV/XCHG/LEA/LDS/LES/XLAT`、`PUSH/POP/PUSHF/POPF`、
  `ADD/ADC/SUB/SBB/CMP/INC/DEC/NEG/MUL/IMUL/DIV/IDIV`、`AND/OR/XOR/NOT/TEST`、
  移位与循环移位、`JMP/Jcc/LOOP/CALL/RET/IRET/INT/INTO`、`IN/OUT`、
  串操作与 `REP` 前缀、`CLI/STI/CLD/STD/HLT/NOP` 等。
- `INT 21H` 支持 09H（显示字符串）、02H（显示字符）、4CH（结束）；无其他 DOS 功能。
- 不支持 32 位指令、保护模式、宏、外部链接和字节级定位（`$` 不精确）。

- `F5`：暂停 / 继续
- `Ctrl+R`：复位

## 仿真约定

- CPU 默认 4 MHz（可切 2/4/8/16/33 MHz），按指令周期折算时间；8253 时钟、
  8259 边沿、0809 转换时间均按虚拟时间推进。
- 数码管和点阵采用 50 ms / 40 ms 视觉暂留模型，扫描程序看起来是稳定显示的。
- 软件延时循环的绝对时间会随 CPU 主频变化；需要精确计时时用 8253 + 中断。
